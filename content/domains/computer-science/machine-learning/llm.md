# LLM

Large language model. Predicts the next token, trained on a lot of text.

- Built on [[Transformers]].
- Generation is token by token. [[Key-value Cache]] keeps past attention work so each new token is cheaper.
- Using it to maintain notes: [[Persistent LLM wikis make synthesis compounding]], [[LLM Wiki]].
