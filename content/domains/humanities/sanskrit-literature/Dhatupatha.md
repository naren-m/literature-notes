# Dhatupatha (धातुपाठ)

List of verb roots (धातु) that [[Ashtadhyayi]] works on. Root + suffix → word.

- About 2000 roots, in 10 gaṇas (classes). The class decides how the root conjugates.
- Each entry = root + meaning in the locative: **स्त्यै शब्दसङ्घातयोः** = styai, in the sense of sound and becoming dense.
- Reference like DP 01.1058 = gaṇa 1, root 1058. Numbering differs a little between editions.
- Roots are listed in their upadeśa form, with markers (anubandha) that rules read. Example: स्त्यै ends in ai, so 6.1.45 turns it to स्त्या.
