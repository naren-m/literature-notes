# Kent Beck

Software engineer. Created Extreme Programming (XP).

- Rediscovered and popularised [[Test Driven Dev]]. Book: "Test-Driven Development: By Example" (2002).
- Wrote JUnit with Erich Gamma.
- Signed the Agile Manifesto.
