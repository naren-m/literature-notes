# Kṛt pratyaya (कृत् प्रत्यय)

Suffix added straight to a root → noun or adjective. Root → word.

- 3.1.93 कृदतिङ् = a suffix added to a root that is not a verb ending (tiṅ) is kṛt.
- Word ending in kṛt = kṛdanta. √kṛ + tṛc → kartṛ (doer).
- vs taddhita: taddhita goes on a noun (Vasiṣṭha → Vāsiṣṭha). Kṛt goes on a root.
- Examples: ka (3.2.3 → godaḥ, giver of cows), ktin (√kṛ → kṛti), ti.

Root comes from → [[Dhatupatha]]. Kṛt word + its object → [[Upapada samasa]].
