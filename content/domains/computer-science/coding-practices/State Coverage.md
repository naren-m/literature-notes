# State Coverage

How many of the system's states and transitions the tests actually drive.

- Line and branch coverage can be 100% while state combinations stay untested.
- Behavior tests (integration, E2E) cover states better. Unit tests cover branches. → [[Testing Principles]], [[Testing Pyramid]]
- Not a standard metric. No single definition or tool.
