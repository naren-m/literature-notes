# Zero Day Attack

Hacker exploits the vulnerability before developers find a fix → zero day attack.

- Zero day = timing advantage, not a technical category.
- Can be any broader software vulnerability ([[Security Vulnerabilities]]):
  - missing [[Encryption|data encryption]]
  - SQL injection
  - [[Buffer Overflows]]
  - missing authorizations
  - broken algorithms
  - URL redirects
  - bugs
  - problems with password security
- Hard to find proactively. Good news: hackers struggle too. Bad news: hard to guard against.
- Can't patch the unknown → limit the blast radius: least privilege, monitoring, segmentation, fast patch path.
