# JSON

JavaScript Object Notation.
Douglas Crockford specified it.

- Text. Objects, arrays, strings, numbers, booleans, null. That's it.
- Humans can read it, every language can parse it → web APIs, config files, tokens.
- JSON is only representation. Trust comes from around it: [[Token Authentication]], signatures, schemas, careful parsing.
