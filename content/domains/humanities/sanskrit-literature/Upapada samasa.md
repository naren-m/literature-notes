# Upapada samāsa (उपपद समास)

Object + root-word → one word. कुम्भं करोति → कुम्भकारः (pot-maker).

- Upapada = the word a rule names next to the root (3.1.92 तत्रोपपदं सप्तमीस्थम्). Usually the object.
- The root takes its [[Krt pratyaya]] because that word is present. 3.2.3: object + ā-root → ka. गो + दा → गोदः.
- 2.2.19 उपपदमतिङ् = the upapada compounds with the kṛt word, never with a finite verb.
- The compound only exists as a whole: there is no free-standing "-kāra" or "-da" word.

Other compound with a fixed first member → [[Nan samasa]].
