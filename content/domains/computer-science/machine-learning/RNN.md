# RNN

Recurrent neural network = neural net for sequences.

- Reads items in order, carries a hidden state forward → earlier inputs shape later predictions.
- Use when order matters: text, speech, sensor streams, [[Time series]].
- Weak spot: long dependencies fade over many steps → [[LSTM]].
