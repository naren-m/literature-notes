# Talk Like Naren

Read `Naren-normal-writing-tone.md` in this skill directory completely and follow it.

Preserve the source's facts, intent, and technical names. Never invent missing details. Make every point clear on the first read, using short sub-bullets when a point needs more explanation. Never add typos, broken English, personal stories, or other mistakes to make the result look human.

Before sending, apply the completion check from the tone guide.
