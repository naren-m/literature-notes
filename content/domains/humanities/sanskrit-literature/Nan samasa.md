# Nañ samāsa (नञ् समास)

Not + word → one word. na brāhmaṇaḥ → abrāhmaṇaḥ.

- 2.2.6 नञ् = na (as nañ) compounds with the following word.
- 6.3.73 नलोपो नञः → n drops → a-. na + ga → aga.
- 6.3.74 तस्मान्नुडचि → before a vowel, n is added back → an-. na + aśva → anaśvaḥ.
- Meaning: absence (abhāva), or "other than / like but not" (abrāhmaṇa = not a brāhmaṇa).
