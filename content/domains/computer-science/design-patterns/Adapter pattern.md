# Adapter pattern

Make one interface look like the one the client expects. A wrapper.

- Travel plug adapter. Same power, different shape.
- Adapter changes the interface. [[Decorator Pattern]] keeps the interface and adds behavior.
- One of the [[Structural Patterns]].
