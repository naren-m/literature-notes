# Encryption

Encryption transforms readable plaintext into ciphertext so that only someone with the required key can recover the plaintext. Its main security property is [[Confidentiality]].

Symmetric encryption uses the same secret key to encrypt and decrypt. Asymmetric encryption uses a public and private key pair. In both cases, the algorithm and key-management rules determine whether the protection is useful.

Encryption is different from [[Digital signatures]]. Encryption hides content; a signature helps verify origin and [[Integrity]]. [[Key exchange]] is the process used to establish shared cryptographic material before a symmetric session.
